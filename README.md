# Sacred Atlas

A global directory and interactive map for discovering independent retreat, wellness, and community providers.

## Project goals

- Interactive, searchable provider map and directory
- Provider profiles with owner claim and verification workflow
- Booking inquiry requests routed to providers for confirmation
- Community discussions and resource listings
- Responsible provider outreach with source tracking and opt-out management

## Current status

Repository initialized. The supplied compiled website archive is being prepared for integration. Dynamic features that require persistence (provider claims, booking requests, accounts, and forum posts) require a backend service and database; a static frontend deployment alone will not enable those workflows.

## Deployment

Planned: Render, connected to this GitHub repository after the frontend and backend build configuration are committed.
